# ADR 0001 — модульный монолит, общий сервис записи и PostgreSQL
Статус: принято 2026-11-17.

FastAPI — единая точка записи для React, импорта и AI. Контактная карточка сохраняется атомарно вместе с контактами, тегами, работой и знакомствами. PATCH принимает полную редактируемую карточку и expected_version; частичное объединение полей не выполняется. Это делает удаление строк и сравнение AI-предложений явным. Конкурентное изменение приводит к 409.

UUID и составные FK (workspace_id, id) запрещают межпространственные ссылки. Runtime-роль без superuser/BYPASSRLS; RLS на контактных данных. Контекст workspace устанавливается только после проверки членства. Таблицы входа/членства/токенов обслуживают авторизацию вне RLS; доступ к ним ограничивается сервером. RLS защищает от пропущенного фильтра, не от произвольного SQL при компрометации backend.

PostgreSQL хранит сессии, лимиты входа, предложения и аудит. Redis/Neo4j/внешние AI API не нужны. Для обработки импортов достаточно идемпотентных job_key/record_key в предложениях. Отдельный асинхронный планировщик — будущая задача.

Личные приоритеты принадлежат участникам; редактирование карточки не позволяет изменить чужой приоритет. Симметричные связи канонизируются по UUID. Направленные связи обходятся вперёд. Граф ограничен 2 уровнями; поиск пути — 6 уровнями и 80 узлами по умолчанию, максимум 150, с явным индикатором усечения.

Зависимости закреплены в requirements.txt/package-lock.json. Используются текущие установленные стабильные API, включая TanStack Table v9. Миграция содержит замороженный SQL; изменения моделей требуют новой миграции.
