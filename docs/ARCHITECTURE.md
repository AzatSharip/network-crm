# Архитектура

React/Vite обслуживается nginx и обращается только к `/api/v1`. FastAPI проверяет серверную сессию или ограниченный bearer-токен, затем членство и роль в пространстве. SQLAlchemy транзакция устанавливает RLS-контекст. PostgreSQL — единственный источник истины.

- `app/models.py`: нормализованные модели и индексы.
- `app/schemas.py`: строгие входные контракты, URL/идентификаторы.
- `app/security.py`: сессии, CSRF, Argon2id, роли, счётчики входа.
- `app/services.py`: общая атомарная запись карточки/отношений и аудит.
- `app/main.py`: маршруты API, bounded graph, AI review, поиск.
- `migrations/`: замороженные миграции, RLS, ограничения.
- `frontend/src`: русский интерфейс, модальная форма с focus trap, TanStack Table и Cytoscape.

Транзакция коммитится после успешного обработчика; ошибка откатывает данные и статус предложения. AI approve блокирует предложение, проверяет версию и вызывает тот же сервис записи. Аудит содержит метаданные действий, а не копии контактных данных. Предыдущее содержимое AI-предложения хранится только внутри соответствующего workspace.

Контактные методы и организации обновляются в составе полной карточки. Это исключает частично сохранённые формы. При конфликте версии клиент должен перечитать карточку. Идемпотентность создания — `Idempotency-Key`; импортов — пара job_key/record_key. Изменение тела с тем же ключом возвращает 409.
