# Roadmap

После проверенного MVP: MFA/passkeys, управление ролью/исключением участника с инвалидацией токенов, восстановление пароля через отдельную доверенную административную процедуру, удаления/экспорт с политикой хранения, история взаимодействий, отдельные источники для каждого факта, дозаполнение AI по полям, CSV/vCard/Telegram парсеры с preview, фоновые import jobs, настройки колонок и доступность графа с клавиатуры.

События: универсальная events(id, workspace_id, title, date, recurrence, description), event_persons для нескольких людей; родственник не обязан иметь карточку. Повторяемость once/yearly/rrule. Напоминания и поздравления требуют отдельного согласия; автоматическая отправка сейчас отсутствует.

Поиск: интерфейс SearchService допускает дополнительное семантическое ранжирование pgvector без изменения основного API. Внешние AI сервисы и отправка переписок требуют отдельного решения владельца.

Модель Workspace допускает будущие team/business типы новой миграцией. Публичные профили и социальная лента не планируются.
