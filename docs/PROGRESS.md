# Состояние MVP — 2026-11-17

Реализованы Personal/Family, роли и приглашения, гибкие контакты, организации/теги, связи участников и людей, поиск, bounded graph/path, AI Inbox с подтверждением и конфликтами, ограниченные токены импорта. Русский адаптивный UI работает с реальным API/PostgreSQL. Пароли/сессии/CSRF, RLS и составные FK защищают границы данных. Смена пароля отзывает все сессии.

Atlas: собственный приватный Compose стек, аккаунт владельца создан безопасным bootstrap, два пустых пространства, вход/выход проверены. Ежедневная зашифрованная копия и restore-check включены; первая копия восстановлена в отдельную БД. Зашифрованная копия и независимая копия ключа сохранены на Mac, SHA-256 и расшифровка проверены. Автоматический off-host перенос пока не настроен.

Незавершённое: независимое exact-commit review/integration; согласование и включение добавочного маршрута общего HTTPS ingress; проверка реального HTTPS-входа/CSRF и auto-renew; разрешение первой публичной публикации (MIT выбрана владельцем). MFA отсутствует: в MVP случайный пароль, ограничение попыток и защищённые серверные сессии; усиление MFA описано в SECURITY/ROADMAP.

Локальный Colima: bind mounts из macOS Documents зависают. Обход — сборка из пакета исходников в гостевой /tmp и immutable DB image, отдельный network-crm-local. Не перезапускать общий Docker/Colima: там работают другие сервисы. Исключены macOS AppleDouble metadata из Docker context. Старый собственный контейнер network-crm-db-1 остался Created из неудачного bind mount; не трогать чужие контейнеры/volumes.
