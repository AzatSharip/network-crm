# Поиск

Поисковый документ обновляется сервисом сохранения в той же транзакции, что карточка. Он объединяет имя/ФИО, альтернативные имена, географию, профессию, компетенции, описание/заметки, исходные и нормализованные идентификаторы, подписи, теги, названия организаций и должности.

Generated tsvector: русское имя вес A, русский документ B, simple-документ C. GIN по tsvector и GIN pg_trgm по search_text. Запрос разбивается максимум на 12 слов (до 200 символов), для каждого требуется русское FTS, simple FTS, частичное ILIKE либо trigram word similarity >= 0.45. Слова могут находиться в разных атрибутах. Регистр не учитывается. `%`/`_` и SQL-подобные строки трактуются как данные. Фильтры city/country/profession точные без регистра, tag точный, priority личный, known_by по связи участника.

Ранжирование: точное имя, затем ts_rank_cd, затем similarity имени; стабильное завершение сортировки по display_name и id. Частичные идентификаторы находятся через документ. Нормализация контактных методов описана в DATA_MODEL.

Каждый запрос ограничен проверенным workspace, дополнительно действует RLS. Ответ содержит total, page, size, items. Пагинация серверная, UI debounce 250 мс и защита от устаревших ответов.

Фактический benchmark на 10 000 синтетических карточек и EXPLAIN будут внесены в docs/VALIDATION.md после запуска, до этого производительность не подтверждена.
