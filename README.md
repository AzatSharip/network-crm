# Network CRM
Персональная и семейная CRM: поиск людей, универсальные контакты, граф знакомств и подтверждаемые AI-предложения. Интерфейс на русском. Проект в разработке; текущие проверки и незавершённые критерии — [PROGRESS](docs/PROGRESS.md).

Стек: React/TypeScript/Vite, FastAPI/SQLAlchemy/Alembic, PostgreSQL. Данные и секреты хранятся вне исходников. Публичная регистрация отключена. Первый публичный push требует подтверждения владельца; лицензия пока не выбрана.
